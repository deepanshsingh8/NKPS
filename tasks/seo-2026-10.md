## P1 — Speed (biggest ranking lever found)

Mobile LCP is 5.3–5.6s (target < 2.5s). Images finish downloading at ~1.3s and
then wait ~4s to be painted — content is server-rendered at `opacity: 0` and
only revealed once JavaScript hydrates.

- [x] `PageHeader.tsx`: the H1 block started at `initial={{ opacity: 0 }}` (every
      inner page). Now a CSS-only, transform-only entrance (`animate-in
      slide-in-from-bottom-8`), so it runs before JS and never hides the H1
- [x] `AnimatedSection` (shared, website-only): same problem for every section
      below the header. On `/about` that heading was the LCP. Now
      transform-only (`y: 24 → 0`, opacity stays 1)
- [x] Home hero: slide 0 now `loading="eager"` + `fetchPriority="high"`.
      Next 16 deprecated `priority`, and the preload it emitted carried no fetch
      priority. `/about`, `/facilities` and article covers moved `priority` → `preload`
- [x] `/gallery`: the first-row event covers were lazy and wrapped in
      `opacity: 0` motion divs. Now transform-only, first 3 eager, first one high
      priority. Server HTML has 0 hidden elements (was 21)
- [x] `/admissions`: the enquiry pop-up now opens on the first scroll past a third
      of a screen instead of a 600ms timer. It still opens on every visit, but no
      longer covers the page on arrival and can't become the LCP. Verified:
      closed on load and at 150px, opens at 400px
- [ ] Measure on the Vercel preview deployment (PSI mobile), record before/after here.
      Production baseline (Lighthouse 12 mobile, 2026-10-01): `/` LCP 5.5s perf 77 ·
      `/admissions` 5.3s perf 79 · `/gallery` 5.6s perf 78 · CLS 0 everywhere

Investigated and ruled out: React hydration error #418 appeared on every
production page in the Browser pane, but Lighthouse's clean Chrome logged no
console errors and a UTC production build doesn't reproduce it, so it comes
from the pane, not the site.

Remaining `opacity: 0` in the server HTML (`/about` 13, `/admissions` 15) are
staggered card grids below the first screen; they don't affect LCP. Left as is.
