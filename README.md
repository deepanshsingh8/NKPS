# NK Public School (NKPS)

School website built with Next.js, TypeScript, Tailwind CSS, and Supabase.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — run production server
- `npm run lint` — ESLint

## Environment

Copy `.env.example` to `.env.local` and set your Supabase URL and keys (see project docs).
